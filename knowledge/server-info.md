# Thông tin server

Tên server: Craftopia.

IP/hostname Java: `play.craftopics.online`. Người chơi Java có thể nhập trực tiếp địa chỉ này; nếu client yêu cầu port thì dùng port Java do staff công bố, không lấy port Bedrock làm port Java.

IP/hostname Bedrock/Pocket Edition (PE): `play.craftopics.online`.

Port Bedrock/PE: `19132`.

Phiên bản hỗ trợ: Java 1.21.11. Người chơi Bedrock kết nối qua Geyser.

# Tham gia server

Mở Minecraft, vào Multiplayer, chọn Add Server rồi nhập địa chỉ tương ứng.

- Java: nhập `play.craftopics.online`.
- Bedrock/PE: nhập server address `play.craftopics.online` và port `19132`.

Nếu không kết nối được, hãy gửi ảnh lỗi và cho biết đang dùng Java hay Bedrock/PE, phiên bản game và thiết bị.

# Những điều AI không được tự đoán

AI không được tự bịa port Java, lịch bảo trì, chế độ chơi, lệnh, rank, giá bán, luật hoặc chính sách chưa được quản trị viên thêm vào kho kiến thức.
