# Không kết nối được Craftopia

Kiểm tra đã nhập đúng địa chỉ `play.craftopics.online`. Người chơi Bedrock/PE phải nhập port `19132`.

Hãy kiểm tra đúng phiên bản game, khởi động lại Minecraft, tắt VPN/proxy nếu có và thử đổi mạng. Nếu vẫn lỗi, gửi ảnh nguyên văn thông báo lỗi, nền tảng Java hay Bedrock/PE, phiên bản game, thiết bị và thời điểm xảy ra.

# Resource pack

Nếu resource pack không tải, đặt Server Resource Packs thành Enabled, thoát server rồi kết nối lại. Có thể xóa cache server resource pack cũ trước khi thử lại. Không tải pack từ nguồn không do Craftopia công bố.

# Bedrock và Geyser

Craftopia cho người chơi Bedrock/PE kết nối qua địa chỉ `play.craftopics.online`, port `19132`. Một số giao diện, animation, item tùy chỉnh hoặc thao tác tay phụ có thể khác Java vì giới hạn tương thích. Nếu item hiển thị sai, gửi ảnh item, tên item và phiên bản Bedrock cho staff.
