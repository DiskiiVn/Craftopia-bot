# Resource pack

Nếu pack không tải, hãy thoát server, kiểm tra Resource Packs của server đang đặt là Enabled, xóa pack cũ trong thư mục server-resource-packs rồi kết nối lại.

# Java và Bedrock

Người chơi Java dùng địa chỉ Java. Người chơi Bedrock dùng địa chỉ và port Bedrock. Một số giao diện hoặc custom item có thể hiển thị khác nhau do giới hạn giữa hai phiên bản.

# Báo lỗi

Khi báo lỗi, hãy gửi: tên Minecraft, Java hay Bedrock, phiên bản game, thời gian xảy ra, ảnh/video và các bước dẫn tới lỗi. Không đăng mật khẩu hoặc token.
